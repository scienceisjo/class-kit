🗂️ 질문 보드 — 단원별 모아보기

학급 질문을 단원(성취기준) 기준으로 모아봐요 · 위 필터(학년·반·과목)가 함께 적용됩니다

⚡ 빠른 피드백 — 질문에 도장 찍기

질문 한 장씩 넘기며 숫자키 1~6 으로 도장 · 학생 화면에 바로 보입니다 · 위 필터(학년·반·기간)가 함께 적용됩니다

🏷️ 라벨 — 내 기준으로 분류하기

질문 유형 자동 분류는 남의 기준이에요 · 여기 쌓이는 이름표가 내 수업의 언어가 됩니다 · 학생에게는 보이지 않아요

🌿 되묻기 일괄 — 차시별로 한 번에

질문을 뽑아 AI 에게 초안을 받고 한 줄씩 확인한 뒤 올립니다 · 올린 되묻기는 학생 화면에 바로 보여요

📋 학생 계정 일괄 생성

CSV 또는 Excel 명렬표를 업로드하면 학생 계정이 한 번에 만들어집니다.
학생들은 학년·반·번호·비밀번호로 바로 로그인할 수 있어요.

1️⃣ 학생이 스스로 가입해요

이 설치본은 서버 함수 없이 돌아가서, 계정을 대신 만들어 주지 않습니다. 대신 학생이 학생 앱에서 학년 · 반 · 번호 · 이름 · 비밀번호만 넣으면 바로 계정이 생겨요(이메일 불필요).

학생 앱 주소:

2️⃣ 수업 시간에 이렇게

① 칠판에 주소(또는 QR)를 띄운다 → ② «가입» 탭 → ③ 학년·반·번호·이름·비밀번호(4자 이상) → ④ 가입 완료 후 첫 로그인.
같은 학년·반·번호로는 한 번만 가입돼요. 비밀번호를 잊으면 이 대시보드의 학생 목록에서 🔑 로 초기화합니다.

3️⃣ 가입 현황 확인

가입이 끝나면 «↻ 새로고침»으로 학생 목록을 갱신해 빠진 학생이 없는지 보세요.

1️⃣ 명렬표 양식 다운로드

아래 버튼을 눌러 양식을 받고, Excel에서 학생 정보를 입력하세요.
컬럼 순서: 학년 / 반 / 번호 / 이름 / 비밀번호

2️⃣ 작성된 명렬표 업로드

CSV(.csv) 또는 Excel(.xlsx) 파일을 선택하세요.

3️⃣ 계정 생성 실행

미리보기가 정상이면 아래 버튼을 누르세요. 학생당 약 1초씩 걸립니다.
